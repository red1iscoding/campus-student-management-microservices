# Campus Student Management Microservices

A microservices-based campus management system designed to manage students, courses, universities, and intelligent assistance through an AI chatbot.  
The project integrates independent backend services with a React frontend, an API Gateway, and a GraphQL layer to centralize and optimize data access.

## Project Overview

This system was developed as part of the **Software Development Engineering** mini-project for **Master 1 - Data Science and Intelligent Systems**.

The main objective is to build a distributed application where each service is responsible for a specific business domain:

- Student management
- Course management
- University association
- Student-course enrollment
- AI-based text translation and summarization
- Centralized API routing
- Optimized data fetching using GraphQL
- Interactive web interface using React
